## 🌟 About Me

I build identity and access systems — increasingly for machines rather than people. As AI agents start acting independently, spawning other agents, and calling each other across systems, the assumptions behind conventional IAM stop holding. That's the problem I work on.

- 🎓 **Final-year BS Cyber Security, FAST NUCES** — 3.74 CGPA, 5× Dean's List, graduating June 2027
- 🔐 **Junior Software Developer @ Protect Lab** — lead developer on BlackGate, co-developer on SecT
- 🤖 **Previously @ Monolayer** — built the IAM system letting clients authorize their own autonomous AI agents, end to end
- 📄 **Published** in *Future Generation Computer Systems* (Elsevier); second paper on Multi-Agent IAM in preparation
- 🧬 **Final year project:** a digital immune system — collaborative agents, continuous trust scoring, and immune memory
- 🎯 **Focused on:** agent-to-agent delegation, scoped credentials, revocation, and policy enforcement across untrusted chains

## 🔥 What I'm Building

**BlackGate** — Blockchain-based identity framework for Industrial IoT
Decentralized identity ledger using Sparse Merkle Trees and ECC P-256 signatures. Device verification in under 15ms, benchmarked across 7,000 simulated devices on 20 fog nodes.

**SecT** — Zero Trust secure transmission system
Rust backend over QUIC with custom STUN/ICE servers for P2P NAT traversal. Fine-grained authorization via Open Policy Agent (Rego) and Ory Keto, plus an agentic layer where connectors act as agents in an automated threat response pipeline.

**MCP Identity Server** — Agent-to-agent delegation and permission security
Custom Model Context Protocol server handling authenticated delegation, scoped credentials, and token revocation between autonomous agents.

**Digital Immune System** *(FYP, in progress)* — Shared collaborative agents, continuous trust scoring, immune memory, and a response engine.
